# Tech Context

**Last Updated:** 2026-08-08 (authored at project scaffold; refresh with
`/context-sync` after `/repo-discovery`)

The live technical snapshot of this repo. Regenerated by `/context-sync` —
if this contradicts `pubspec.yaml`, `pubspec.yaml` wins and this file is stale.

## Toolchain

- Flutter `3.44.8` (stable), Dart `3.12.2`
- SDK constraint in `pubspec.yaml`: `^3.12.2`
- Target platforms: **android, ios** only. No web/desktop — the secure-storage
  story does not hold on web, and this is a mobile-first app.

## State management

- **`flutter_bloc` `^9.1.1`** / `bloc` `^9.2.1`
- **Event-driven `Bloc` everywhere. No `Cubit`.** Every state transition is
  triggered by an event.
- Events and states are **sealed hierarchies extending `Equatable`**
  (`equatable ^2.1.0`) — sealed for exhaustive `switch` in the UI, `Equatable`
  so `bloc_test`'s `expect:` compares by value.
- State variant naming: `XInitial` / `XLoadInProgress` / `XLoadSuccess` /
  `XLoadFailure`. The empty case is a success carrying an empty collection, not
  a separate variant.
- **Exactly two app-wide blocs**, provided in `lib/app/coffee_app.dart`:
  `AuthBloc` (the router's guard reads it) and `CartBloc` (the nav badge, cart
  screen, and checkout all read it). Every other bloc is created in its route's
  `builder` and dies with the route.
- No `bloc_concurrency` — event handlers for the same type may run
  concurrently, so re-entrancy is guarded with a state check (see
  `CheckoutBloc._onSubmitted`).

## Navigation

- **`go_router` `^17.4.0`**
- Router in `lib/app/router/app_router.dart`; paths and names as constants in
  `app_routes.dart`. Navigate by **name**, never a literal path.
- `StatefulShellRoute.indexedStack` with three branches (menu, orders, profile),
  each keeping its own navigation stack. Cart and checkout sit **above** the
  shell — full-screen, no bottom nav.
- Auth guard: a single top-level `redirect` (`AppRouter._guard`) reading
  `AuthBloc.state`. Routes are protected **by default**; only paths in
  `AppRoutes.unauthenticatedPaths` are open.
- `refreshListenable: GoRouterRefreshStream(_authBloc.stream)` — a bloc is a
  `Stream`, not a `Listenable`, so that adapter
  (`lib/app/router/go_router_refresh_stream.dart`) is what makes a sign-out
  bounce the user off a protected screen immediately.

## Models and codegen

- **`freezed ^3.2.5`** + **`json_serializable ^6.14.1`**, run via
  `build_runner ^2.15.1`.
- freezed 3.x syntax: models are declared `abstract class X with _$X`, plus a
  private `const X._()` constructor when the class has getters or methods. The
  2.x `class X with _$X` form does **not** compile here.
- `--delete-conflicting-outputs` was removed in this `build_runner`; the plain
  command is `dart run build_runner build`.
- Domain entities carry their own `fromJson`/`toJson` with `@JsonKey(name:)` for
  snake_case wire fields — there is no separate DTO+mapper layer. See
  `memory-bank/architecture.md` for why.
- **Money is `int` cents**, never `double`. `lib/core/money/money.dart` wraps it.
  Entities store `...PriceCents` fields so JSON round-trips exactly.

## Data layer

- **No HTTP client yet.** Every repository is an in-memory fake behind an
  abstract interface, bound in `lib/app/coffee_app.dart` — the only file that
  names a concrete implementation. Adding `dio`/`http` is a deliberate future
  step, not an oversight.
- `FakeCheckoutRepository` (writes) and `FakeOrderRepository` (reads) share one
  `InMemoryOrderStore` instance, which is why a placed order appears in history.
- Single failure hierarchy: `lib/core/error/app_exception.dart` —
  `NetworkException`, `NotFoundException`, `UnauthorizedException`,
  `ValidationException`, `UnexpectedException`. Repositories map **everything**
  onto these, including `PlatformException` from secure storage. Blocs catch
  `on AppException` only.

## Security

- **`flutter_secure_storage ^11.0.0`**, accessed only through
  `lib/core/storage/secure_token_store.dart`. No `SharedPreferences` in the
  project at all.
- No real payment integration. `PaymentMethod` is an enum of labels; no card
  data, tokens, or PANs exist anywhere in the codebase.
- Auth events override `toString()` to redact the password, because bloc
  observers and crash reporters print events.

## Testing

- **`bloc_test ^10.0.0`** + **`mocktail ^1.0.5`**. No `mockito`.
- **91 tests passing**, `flutter analyze` clean.
- Bloc tests assert the emitted state sequence via `blocTest`, always covering a
  success **and** a failure path.
- Widget tests either provide a real bloc over a faked repository (behaviour
  through real transitions) or a `MockBloc` with a stubbed state (pinning one
  render state). `registerFallbackValue` is required in `setUpAll` for every
  non-primitive type passed to `any(named:)`.
- No `integration_test/` yet. No golden tests — do not introduce them without
  asking (`04-flutter-test-guard.mdc`).

## Not yet wired

- **No crash reporting** (no Crashlytics/Sentry). This is a
  `/production-readiness-review` blocker before any real release.
- No localization — all strings are inline English literals. `/flutter-l10n-gen`
  and `intl` would be the first step; date and currency formatting are currently
  hand-rolled single-locale helpers (`Money.formatted`,
  `OrderTile._formatDate`).
- No analytics, no push notifications, no deep-link handling beyond
  `go_router`'s own path parsing.
