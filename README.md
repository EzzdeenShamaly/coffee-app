# Coffee App
A coffee shop mobile app built with Flutter, using BLoC/Cubit for state management and a feature-based Clean Architecture (each feature split into application/data/domain/presentation layers).
## Features
- Menu browsing, cart, checkout, and order management
- User authentication and profile management
- Secure token storage
## Tech Stack
- **State Management:** BLoC / Cubit (flutter_bloc, equatable)
- **Architecture:** Clean Architecture (feature-based)
- **Routing:** go_router
- **Data modeling:** Freezed, json_serializable
- **Storage:** flutter_secure_storage
